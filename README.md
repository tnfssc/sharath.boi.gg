## Instructions

- You can start the dev server using the following commands:

```sh
# Add .env file
cp .env.example .env
vim .env

# Install tools
mise trust
mise install
npm i -g pnpm

# Install dependencies
pnpm install

# Start the dev server
pnpm dev
```

- Open `http://localhost:5173` in your browser to view the website.
